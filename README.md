# ✊✋✌️ Rock Paper Scissors Game

A fun and interactive **Rock Paper Scissors** game built using **HTML5, CSS3, and JavaScript**. Play against the computer, receive instant results, and enjoy a clean and responsive user interface.

## 🚀 Live Demo

🔗 **https://malikauppala.github.io/Rock-Paper-Scissors-Game/**

---

## ✨ Features

- 🎮 Play against the computer
- ✊ Rock, ✋ Paper, ✌️ Scissors choices
- 🤖 Random computer moves
- 🏆 Instant win, lose, or draw result
- 📱 Responsive design
- ⚡ Smooth and interactive gameplay
- 🎨 Clean and attractive user interface

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Malikauppala/Rock-Paper-Scissors-Game.git
```

### Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Select **Rock**, **Paper**, or **Scissors**.
5. The computer will randomly choose its move, and the game result will be displayed instantly.

---

## 🎯 Game Rules

- ✊ Rock beats Scissors
- ✌️ Scissors beats Paper
- ✋ Paper beats Rock
- If both players choose the same option, the game ends in a Draw.
